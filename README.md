# Superstore Sales Analysis Dashboard

## Project Overview

This project analyzes retail sales data from the Superstore dataset to identify key business insights such as sales trends, regional performance, customer contribution, and product profitability.

The goal of the project is to demonstrate how data analysis and visualization can help businesses make data-driven decisions.

---

## Tools & Technologies Used

* **Excel / CSV** – Dataset source and initial cleaning
* **SQL** – Data querying and KPI analysis
* **Power BI** – Interactive dashboard and data visualization

---

## Dataset

The dataset used is the **Sample Superstore dataset**, which contains information about orders including:

* Order Date
* Customer Name
* Region
* Category & Sub-category
* Sales
* Profit
* Quantity
* Discount

---

## Key KPIs Analyzed

The dashboard tracks the following key performance indicators:

* **Total Sales**
* **Total Profit**
* **Total Orders**
* **Profit Margin**

These KPIs help evaluate overall business performance.

---

## Dashboard Features

### 1. Sales Trend Analysis

A line chart showing **monthly sales trends from 2014–2017**, helping identify seasonal patterns and growth.

### 2. Regional Sales Performance

A bar chart comparing sales across regions to identify the **best performing markets**.

### 3. Top Customers

A table showing the **Top 10 customers by total sales**, useful for identifying high-value clients.

### 4. Category Performance

Comparison of **Total Sales vs Total Profit by Category** to evaluate business profitability.

### 5. Sub-category Profit Analysis

Visualization showing which product sub-categories generate the highest profit.

### 6. Interactive Filters

Users can filter the dashboard by **Year**, enabling dynamic analysis of business performance over time.

---

## Key Insights

* The **West region generates the highest revenue**.
* Sales show **seasonal growth toward the end of the year**.
* A small number of customers contribute significantly to total revenue.
* Some product sub-categories are highly profitable compared to others.

---

## Conclusion

This project demonstrates how business intelligence tools such as **Power BI** can transform raw data into meaningful insights that support better decision-making.
